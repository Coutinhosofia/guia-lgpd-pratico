#Checklist de Adequação à LGPD

Use este checklist para verificar se sua empresa está em conformidade com a LGPD.

---

## 1. Mapeamento de Dados
- [ ] Identificar todos os dados pessoais coletados
- [ ] Mapear como os dados são coletados, armazenados e utilizados
- [ ] Identificar quem tem acesso aos dados
- [ ] Documentar o fluxo de dados (entrada, processamento, saída)

## 2. Bases Legais
- [ ] Identificar a base legal para cada tipo de tratamento
- [ ] Obter consentimento explícito quando necessário
- [ ] Documentar todas as bases legais utilizadas

## 3. Políticas e Documentos
- [ ] Criar ou atualizar a Política de Privacidade
- [ ] Criar aviso de cookies (para sites)
- [ ] Elaborar contratos com operadores (fornecedores que tratam dados)
- [ ] Criar política interna de proteção de dados

## 4. Direitos dos Titulares
- [ ] Criar canal para atendimento de solicitações dos titulares
- [ ] Definir processo de resposta às solicitações (prazo máximo 15 dias úteis)
- [ ] Criar formulário de solicitação de direitos

## 5. Segurança da Informação
- [ ] Implementar controles de acesso (quem pode ver quais dados)
- [ ] Utilizar criptografia para dados sensíveis
- [ ] Realizar backups seguros
- [ ] Definir política de senhas
- [ ] Implementar autenticação em dois fatores para sistemas críticos

## 6. Encarregado (DPO)
- [ ] Nomear um Encarregado de Proteção de Dados (DPO)
- [ ] Publicar os dados de contato do DPO
- [ ] Registrar o DPO na ANPD (quando exigido)

## 7. Treinamento
- [ ] Treinar todos os colaboradores sobre a LGPD
- [ ] Treinar equipes que lidam com dados pessoais especificamente
- [ ] Documentar os treinamentos realizados

## 8. Incidentes
- [ ] Criar plano de resposta a incidentes de segurança
- [ ] Definir processo de notificação à ANPD (em até 72h)
- [ ] Definir processo de comunicação aos titulares afetados
