# Checklist de Resposta a Incidente de Dados

Use este checklist em caso de vazamento ou incidente envolvendo dados pessoais.

---

## Primeiras 2 horas
- [ ] Identificar e isolar o sistema afetado
- [ ] Acionar o time de segurança e o DPO
- [ ] Registrar data, hora e natureza do incidente
- [ ] Preservar evidências (logs, registros)

## Primeiras 24 horas
- [ ] Avaliar o volume e tipo de dados afetados
- [ ] Identificar os titulares impactados
- [ ] Avaliar o nível de risco do incidente
- [ ] Iniciar investigação sobre a causa raiz

## Até 72 horas
- [ ] Notificar a ANPD (se houver risco relevante aos titulares)
- [ ] Preparar relatório do incidente
- [ ] Comunicar os titulares afetados (se aplicável)

## Após contenção
- [ ] Corrigir a vulnerabilidade explorada
- [ ] Revisar controles de segurança
- [ ] Documentar lições aprendidas
- [ ] Atualizar plano de resposta a incidentes
- [ ] Registrar o incidente internamente
