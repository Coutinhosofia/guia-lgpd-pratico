# Direitos do Titular de Dados

Segundo o **Art. 18 da LGPD**, o titular tem os seguintes direitos:

| Direito | O que significa |
|---|---|
| **Confirmação** | Saber se seus dados são tratados pela empresa |
| **Acesso** | Receber cópia dos dados tratados |
| **Correção** | Corrigir dados incompletos, inexatos ou desatualizados |
| **Anonimização/Bloqueio** | Solicitar que dados desnecessários sejam anonimizados ou bloqueados |
| **Eliminação** | Pedir a exclusão dos dados coletados com consentimento |
| **Portabilidade** | Transferir seus dados para outro fornecedor |
| **Informação sobre compartilhamento** | Saber com quais entidades seus dados são compartilhados |
| **Revogação do consentimento** | Retirar o consentimento a qualquer momento |
| **Oposição** | Se opor a tratamentos realizados sem consentimento |
| **Revisão de decisões automatizadas** | Solicitar revisão de decisões tomadas por algoritmos |

---

## Prazos de Resposta

A empresa deve responder às solicitações dos titulares em prazo **razoável** — a ANPD recomenda até **15 dias úteis**.

---

## Como o titular pode exercer seus direitos?

- Pelo canal de atendimento da empresa (e-mail, formulário, etc.)
- Direto com o Encarregado (DPO)
- Através da ANPD em caso de descumprimento
