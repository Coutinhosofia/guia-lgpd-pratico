# Conceitos Fundamentais da LGPD

## O que é a LGPD?

A **Lei Geral de Proteção de Dados (Lei nº 13.709/2018)** é a legislação brasileira que regula o tratamento de dados pessoais por pessoas físicas e jurídicas, com o objetivo de proteger os direitos fundamentais de liberdade e privacidade.

Entrou em vigor em **setembro de 2020** e as sanções passaram a ser aplicadas a partir de **agosto de 2021**.

---

## Conceitos-chave

| Conceito | Definição |
|---|---|
| **Dado pessoal** | Qualquer informação que identifique ou possa identificar uma pessoa (nome, CPF, e-mail, IP, etc.) |
| **Dado sensível** | Dado pessoal sobre origem racial, convicção religiosa, saúde, biometria, orientação sexual, etc. |
| **Titular** | A pessoa física a quem os dados pertencem |
| **Controlador** | Quem decide como e por que os dados são tratados |
| **Operador** | Quem trata os dados em nome do controlador |
| **Encarregado (DPO)** | Responsável por ser o canal entre empresa, titulares e a ANPD |
| **Tratamento** | Qualquer operação com dados: coleta, armazenamento, uso, compartilhamento, exclusão |
| **ANPD** | Autoridade Nacional de Proteção de Dados — órgão fiscalizador da LGPD |

---

## Princípios da LGPD (Art. 6º)

1. **Finalidade** — dados coletados para fins específicos e legítimos
2. **Adequação** — compatibilidade com a finalidade informada
3. **Necessidade** — coleta mínima necessária
4. **Livre acesso** — titular pode consultar seus dados gratuitamente
5. **Qualidade dos dados** — dados devem ser exatos e atualizados
6. **Transparência** — informações claras sobre o tratamento
7. **Segurança** — proteção contra acessos não autorizados
8. **Prevenção** — medidas para evitar danos
9. **Não discriminação** — dados não podem ser usados para discriminar
10. **Responsabilização** — demonstração de conformidade

---

## Sanções previstas

- Advertência
- Multa de até **2% do faturamento**, limitada a **R$ 50 milhões por infração**
- Bloqueio ou eliminação dos dados
- Suspensão do banco de dados
